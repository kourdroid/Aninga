## 2024-05-31 - Keyboard Accessibility for CustomTkinter Buttons
**Learning:** CustomTkinter `CTkButton` and `CTkRadioButton` widgets do not have native visual focus indicators for keyboard navigation. For `CTkButton`, `fg_color` can be modified. For `CTkRadioButton`, modifying `fg_color` only changes the inner checked circle, so `text_color` is a better property to highlight to indicate focus. Additionally, `cget()` returns lists for dynamic theming (e.g., `text_color=['gray10', '#DCE4EE']`), which can be safely passed back into `configure()` to restore defaults.
**Action:** Always manually bind `<FocusIn>` and `<FocusOut>` events to interactive CustomTkinter widgets to ensure clear visual feedback for keyboard users, and restore the dynamic color states using the list format returned by `cget()`.
