## 2024-05-24 - [Requests Connection Pooling]
**Learning:** Making iterative HTTP requests to the same host using `requests.get` inside loops causes redundant TCP/SSL handshakes, significantly degrading download performance for apps like Aninga that fetch many image/video chunks.
**Action:** Always wrap iterative `requests` calls in a `with requests.Session() as session:` context manager to enable connection pooling.
